CE QU'IL FAUT FAIRE SUR LE VPS (Windows)
----------------------------------------
1. Double-clic sur 3-arreter.bat (arrête l'ancien robot).
2. Dans le dossier du robot, remplace bot.js et package.json par ceux de ce dossier.
   Garde ton config.json actuel (il contient la clé secrète). Vérifie juste qu'il contient :
     "phone": "2290168869634",
     "linkMethod": "code"
3. Renomme le dossier « auth » en « auth-ancien » (l'ancienne liaison ne marche plus).
4. Ouvre une invite de commandes dans le dossier et tape :
     npm.cmd install
   (installe Baileys et ffmpeg pour les notes vocales ; patiente 1 à 3 minutes)
5. Double-clic sur 1-demarrer.bat.
6. Le code à 8 caractères s'affiche (il est aussi écrit dans CODE.txt).
   Sur le téléphone du robot : WhatsApp > Appareils connectés > Connecter un appareil
   > « Connecter avec le numéro de téléphone à la place » > saisis le code.
   Le code change toutes les ~60 s : saisis toujours le DERNIER affiché.
7. Quand « Connecté » s'affiche, lance 2-demarrage-automatique.bat (redémarrage auto du VPS).
